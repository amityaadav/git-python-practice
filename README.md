# git-practice

## Fundamentals
Working/Local Directory
(files in your workstation/computer)   

git add: Select which changes to include in your next commit (Staging Area)
if you use "git add .", all fies will be added to staging area. You may add specific files through git add {filename}.

git reset HEAD: to unstage your added changes.

git commit: Saves to .git/ on your project folder.  (local repo on your computer).  Ensure that you leave a comment about what the changes include.

git push origin: Sends to GitHub (Send your changes to remote)

## Fetch vs. Pull
Fetch to download and then review before you merge to your local
Pull to download and merge to your local

Fetch = check your mailbox
Pull = check mailbox + acknowledge bill that have already been paid (existing changes) + pay the new bills (merge changes)
